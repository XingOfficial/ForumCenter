# 论坛中心：专为视障用户打造的无障碍社区客户端

**论坛中心**是一款深度适配视障用户需求的移动应用，无缝集成“天坦社区”与“帮盲社区”，提供从内容浏览、互动发帖到富媒体渲染的一站式服务。

### 核心功能：全场景社区体验

*   **高效浏览**
    *   支持“全部、最新、热门、精华”四大分类标签。
    *   采用下拉刷新与无限滚动加载机制，流畅获取社区动态。
*   **便捷发帖**
    *   支持选择板块标签发布内容。
    *   **智能图片处理**：从相册上传图片后自动转换为 HTML 标签插入；支持长按手动输入图片链接。
*   **即时互动**
    *   **精准回复**：基于 `commentId` 实现真正的层级回复关联，评论局部插入，无需刷新整页。
    *   **实时点赞**：点赞后计数即时更新，无需重新加载详情页。
*   **搜索与管理**
    *   支持全站帖子搜索。
    *   可查看用户个人资料及发帖历史，轻松掌握社区成员动态。
*   **个性化设置**
    *   自定义字体大小，提升阅读舒适度。
    *   支持配置发帖小尾巴（兼容 HTML 链接）。
    *   多社区账号独立管理，切换无忧。

### 双社区支持：一站式访问

**1. 主社区：天坦社区 (bbs.tatans.cn)**
*   **定位**：天坦读屏官方社区，视障用户交流技术、分享生活、反馈问题的核心平台。
*   **全功能支持**：涵盖帖子浏览、详情查看、发帖、评论、回复、点赞、图片上传及 HTML 渲染、标签分类与搜索。

**2. 辅助社区：帮盲社区**
*   **定位**：另一重要视障用户交流平台。
*   **只读支持**：提供完整的浏览体验，包括帖子列表、详情查看、板块分类浏览及富媒体内容渲染。

> *注：两个社区间可无缝切换，体验流畅统一。*

### 富媒体渲染：完整呈现多彩内容

针对天坦社区丰富的 HTML 内容，应用采用 `Html.fromHtml` 结合 `Coil` 异步图片加载引擎，完美解析并渲染以下媒体类型：

*   **图片**：通过 Coil 异步加载，自适应屏幕宽度。
*   **音频/视频**：自动转换为可点击链接，点击后调用系统播放器打开。
*   **超链接**：所有链接均可点击，直接跳转至默认浏览器。
*   **基础排版**：保持段落结构清晰。

### 技术亮点：极致流畅与无障碍优化

*   **网络稳定性**：内置自动重试机制，最多进行 2 次递增延迟重试，确保弱网环境下的连接成功率。
*   **性能优化**：
    *   **首页内存缓存**：快速显示已加载数据，减少等待时间。
    *   **RecyclerView 差分更新**：仅更新变化部分，避免全量刷新带来的卡顿与资源浪费。
*   **深度无障碍适配**：
    *   完善 `heading` 标记，构建清晰的内容层级。
    *   补充详尽的内容描述（Content Description），确保读屏软件能准确传达界面信息。
